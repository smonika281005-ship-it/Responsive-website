# Responsive Website

## Objective
Convert a desktop-only webpage into a **mobile-friendly layout** using **CSS media queries**.

## Tools Used
- HTML5  
- CSS3 (Flexbox + Media Queries)  
- VS Code  
- Chrome DevTools (for testing responsiveness)

## What I Did
1. Added the **viewport meta tag** for proper scaling on mobile devices.
2. Identified fixed-width elements and replaced them with flexible units (`%`, `rem`, `vw`).
3. Used **Flexbox** for layout and applied media queries at `max-width: 768px`.
4. Made the navigation menu stack vertically on smaller screens.
5. Ensured images are responsive with `max-width: 100%; height: auto;`.
6. Filled the **sidebar** with useful content (Quick Links, Contact Info, Featured Image).
7. Added extra sections after the Welcome message (About Us, Services).
8. Tested responsiveness using Chrome DevTools device toolbar.

## Responsive Features
- Navigation menu changes from horizontal → vertical on mobile.
- Sidebar stacks below main content on smaller screens.
- Images scale automatically without overflow.
- Font sizes and spacing adjust for readability on mobile.
